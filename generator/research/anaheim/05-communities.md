# Anaheim — the high-end communities

Researched **2026-08-02** via Firecrawl. Every figure below carries its source. Anything
unverified is marked and belongs in `meta.gaps[]`, not on a page.

**Confidence: medium.** Community detail comes from real-estate sites, which are reliable on
local specifics like lot sizes and street names but are still secondary sources. The city
median is from a listings aggregator. **No primary/government source has been checked yet** —
see "What still needs verifying".

---

## 🔑 THE FINDING THAT CHANGES THE COPY

**Anaheim is not Irvine, and writing it in Irvine's register would be wrong.**

| | Median / typical |
|---|---|
| **Anaheim Hills** (whole area) | **$1,134,500** — *homes.com, up 3% YoY* |
| Irvine · Hidden Canyon | $9.15M |
| Irvine · Altair | $4.59M |
| Irvine · Orchard Hills | $3.51M |
| Irvine · Stonegate | $1.82M |

**Anaheim Hills as a whole sits below Stonegate — Irvine's *entry* tier.** The guard-gated
enclaves inside it reach $1.7M–$3M, and Peralta Hills goes past $6M, but the city-level
register must not borrow Irvine's estate language.

**What to do differently:** Anaheim copy leads with **value transparency and craft**, not
discretion and concierge protocol. Save the white-glove register for Peralta Hills, which
genuinely earns it. Per `DREAM-CUSTOMER.md`, writing all tiers the same way wastes the
expensive ones and alienates the accessible ones.

## ⚠️ DELIBERATELY EXCLUDED — Hidden Canyon, Anaheim

Anaheim Hills **also** has a guard-gated community called **Hidden Canyon** — built 1979,
$1.5M–$3M+, some parcels over two acres, views toward Santiago Oaks Regional Park and the
Cleveland National Forest.

**We already have `/irvine/hidden-canyon/` live.** Two pages for two different places with
the same name would confuse readers and risk Google conflating them.

This is the same trap `06-hoa.md` flagged for Irvine's Stonegate, where two unrelated
associations share a name — *"Do not conflate them."*

**Recommendation: leave it out of the first build.** Four strong communities beat five with
a name collision. If it is added later it must be titled unambiguously — *Hidden Canyon
Estates, Anaheim Hills* — and never just "Hidden Canyon".

## WHAT STILL NEEDS VERIFYING BEFORE COPY

1. **HOA / management company per community.** Only Peralta Hills has a named association so
   far. Irvine's research found one company (Keystone Pacific) controlling four villages —
   the single highest-leverage B2B finding in that market. **Run the same play here:** follow
   `HOA-DISCOVERY-RECIPE.md`, and check whether Anaheim publishes an official HOA lookup the
   way `cityofirvine.gov` does.
2. **Architecture per community.** Only Peralta Hills is described. Palette recommendations
   must fit the actual housing stock, not be generic.
3. **More verified street names** for Peralta Hills and Crown Pointe. Summit Pointe and
   Belsomet have enough.
4. **Whether these communities run design review.** Assumed likely for the guard-gated ones,
   **but assumed is not verified** — and inventing an HOA rule is a hard-rule violation.
5. **A primary source for the median.** $1,134,500 rests on one aggregator.
